Zamfono is a self-hosted phone system (PBX): users, devices, trunks, ring groups, menus and call routing. Every write made here is recorded in the audit log and can be undone. Before configuring anything, call zamfono.help with a topic (mental-model, routing-order, numbers, glossary, guardrails, or a recipe name) to learn the entities and forward-target vocabulary; without a topic it lists every topic.
